He should have treated the model like an **untrusted junior analyst**, not a source.

What he should’ve done differently:

First, **never present AI-generated numbers without source verification**. If a figure is going to a board, it needs a traceable origin: spreadsheet, report, database query, finance system, or named document. Every important number should be answerable with: “Where exactly did this come from?”

Second, **separate drafting from fact production**. AI is fine for summarizing, structuring slides, explaining implications, or turning raw data into plain English. It is not fine as the final generator of factual board data unless the data is directly pulled from verified systems and checked.

Third, **make a verification layer mandatory**. For board-facing material, he should have had a checklist:

- every number tied to a source
    
- every chart matched against source data
    
- every claim checked by a human
    
- every assumption labeled
    
- every uncertain point removed or escalated
    

Fourth, **use primary materials, not model memory**. If he asked the AI something like “what were our Q3 numbers?” instead of giving it the actual dataset, that’s the trapdoor. The model may answer fluently even when it has no basis.

Fifth, **treat high-stakes outputs differently from low-stakes outputs**. Internal brainstorming can tolerate roughness. Board material cannot. Once money, reputation, jobs, legal exposure, or strategy are involved, the standard changes.

The blunt version he may need to hear is this:

He did not fail because “AI was wrong.” He failed because he **outsourced verification**.

That said, this is now a very common failure mode. A lot of people are using models as if polished wording implies grounded truth. It doesn’t. Smooth text is not evidence.

A better operating rule for the future:

**Use AI for synthesis, not authority. Use it to help think, not to decide what is true.**

If he needs something practical, send him this framework for future work:

1. Gather source documents first.
    
2. Ask AI to summarize only those materials.
    
3. Require citations or source references for every key claim.
    
4. Manually verify all numbers and named facts.
    
5. Do a final “board-standard” review with no AI trust assumed.
