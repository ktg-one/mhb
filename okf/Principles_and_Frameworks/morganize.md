## Notable rules
- **sota (00) triage stance:** "user doesn't rate himself = ai must triage for context" — the AI, not Kev, is responsible for surfacing what counts as proof/achievement/impactful context in that bucket.
- **Tagging:** `#todo` for files with obvious action items, `#<domain>`, month/year (`12-2026`), and a reasoning-difficulty tag `#R-<n>` (1=easiest, 10=hardest).
- **Routing destination:** `mv` the file to a domain inbox (`_inbox` / `.inbox` / `inbox`, keyed to whether the source word was raw/drop/triage/todo).
