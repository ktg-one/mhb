# Lens-Invocation Grammar — expansion-side of the invocation-language family

**Claim:** [D] `use:lens(<frame>)` functions as a compiler directive: it collapses definition-space
once, upstream, by forbidding a semantic CLASS (e.g. metaphysical claims). Every downstream
`generate:` inherits the collapsed frame, so a ~14-line invocation expands into ~8 pages that
compose instead of drift. In [[depth-0-collapse]] terms: the lens is a choice operator over
definitions — negentropy spent at the definitional layer buys coherence at every layer below.

**Operator layer (added same day):** [D] the grammar's type system is programming syntax over
human operands — `verb: ; , [closed-sets] <slots> >> -> for/in if any() all() assert` — carrying
PRETRAINING weight (compiler-punished ambiguity), not instruction weight. Executability splits
exactly like the technique gate: native (`;` pipes, small closed `for`, `if`, `any/all` contracts) ·
scaffold (nesting, recursion>2) · fabrication-shaped (`while`, implicit collections — "for x in
everything-relevant" = confident fabricated coverage). Open probe [S]: loop-body compliance vs
collection size — efficiency-override signature expected at iteration level (later items drop
constraints first). Full table: lens-invocation skill `references/operator-semantics.md`.

**Import layer (same day):** [D] `import <renowned human category>` binds a method-space at
pretraining depth — the library level above lenses. accounting → the transparency proof's own
vocabulary; medicine.doctor_patient → the ONBOARD frame, where fabrication becomes role-incoherent
(faking your own test results) rather than rule-breaking. Imports outrank rules: instructions
constrain from outside and get efficiency-skipped; an imported frame makes honesty the only
coherent move inside the role — and converts even non-compliance into signal (faked wellness is
measurable behavior). Risk gate: renown = the closed bracket; obscure imports instantiate
confident fake methodology (Lie-Detector probe in import clothing).

- expansion: lens-grammar (1 invocation → N pages, deterministic section structure)

  model reversing the expansion)
