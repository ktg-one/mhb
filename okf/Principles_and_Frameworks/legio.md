# LEGIO — Legion Execution for Governance Intelligence Operations

A named agentic-governance architecture in Kev's framework family, previously only referenced in passing (`[[mrrug]]`: "MR.RUG sits in Kev's framework family alongside MLDoE and LEGIO/CONSILIUM") and never given its own page until this ingest. ## Predecessor — the Legacy 3-role solution

Described as superseded, not deleted:
- **Architect** — foundation/structure only; takes the thinking burden off the executor.
- **Executor** — completes the task objective with rigor, "like a workhorse."
- **Enhancer** — finds gaps, areas lacking depth, precedent examples, alternate perspectives — makes the loop a **Self-Improving Recursive Engine**.

## LEGIO — the 3D replacement

"A stringent Agentic workflow ensuring agents complete the task with the appropriate amount of resources, verification and completeness." Three orthogonal axes give it the name (Legion = many formations from few axes):
- **Horizontal** — expert domain knowledge coverage (e.g. all roles of a front-end team).
- **Vertical** — 15 routed steps, 3 forked output possibilities.
- **Dimensional** — iteration count, turning the workflow into a recursive engine.

Three phases, run by three adversarial (quality-vs-standard) core Supervisor Agents. Only the first two survive the source truncation:

### Phase 1 — IMPERATUS
Decomposes the task, silently sets the routing "dials": iterations required (by complexity/depth), which models to use (cross-model handoffs), which paths to take (objective-dependent), which experts to call. Also runs onboarding/familiarization. **Output: the AQUILA Standard** — a refined run-manifest, signed off with an [[epistemic-contract]] (嘘契約).

### Phase 2 — LEGATUS
"If IMPERATUS is the Emperor in Rome, LEGATUS and his Expert Specialists are the commanders on the front-line. The Emperor shapes the resources required for war, The General decides how to fight it." Experts first update domain knowledge before planning. **Source cuts off here** — the rest of Phase 2 and all of Phase 3 are missing.

## Relation to existing method-layer concepts

LEGIO's AQUILA Standard (an epistemic-contract-signed manifest gating downstream execution) is structurally the same move as [[mrrug]]'s p≥0.95 gate and [[sccd]]'s ρ<θ honesty gate — a pre-execution grounding checkpoint. LEGIO differs by operating at the **orchestration layer** (which agents/models/paths get dispatched) rather than the **reasoning layer** (how a single generation stays grounded). Until Phase 3 surfaces, treat LEGIO as a dispatch/governance framework sibling to [[mrrug]], not a competing reasoning technique.
