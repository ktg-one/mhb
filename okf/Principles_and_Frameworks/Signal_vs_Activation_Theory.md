Task note requesting a new axis on top of the vault's existing signal-word work ([[pac26]] Pillar 3, and the [[02.5 Signal Test]] instrument): **separate signal words from activation words**, verify the existing table, and fill gaps.

## The [S]/[A]/[D] distinction (new)

Prior work (PAC26 Pillar 3, the Task2 experiment) ranked signal words by *strength* and *freshness* only. This note adds a functional split not previously encoded in the wiki:
- **`[S]` Signal word** — sets frame / priority / attention (e.g. "you are," "forbidden," "process," "source," "success criteria"). Does not itself trigger an operation.
- **`[A]` Activation word** — triggers an operation/action (e.g. "identify," "extract," "enforce," "decompose," "verify," "deliver").
- **`[D]` Dual-use** — grammar-dependent (e.g. "preserve," "ground," "anchor," "verify," "validate" — can frame *or* trigger depending on sentence position).

## Table structure — maps onto PAC26's positional zones

The note organizes signal/activation pairs by the **same five zones** PAC26 Pillar 1 already uses (First 15% / Second 15% / Middle 55% ×2 / Last 15%), pairing each zone with a named "skill" and technique:

| Zone | Skill | Technique | Example signals [S] | Example activations [A] |
|---|---|---|---|---|
| First 15% | Lock Intent | Role + Step Back | you are, role, task, purpose, goal, scope | identify, define, clarify, extract, isolate |
| Second 15% | Guard Rules | Constraint Gate | forbidden, non-negotiable, must, must not, never | enforce, refuse, stop, flag, block |
| Middle 55% | Build Process | SoT + step-by-step + ReAct | process, steps, structure, method, criteria | decompose, distinguish, enumerate, synthesize, score |
| Middle 55% | Rescue Context | XML rescue + source anchoring | source, context, reference, evidence, assumption | extract, quote, cite, attribute, summarize |
| Last 15% | Seal Output | Step Back + Self-Refine + CoVE | success criteria, final audit, checklist, confidence | cross-check, reconcile, audit, finalize, validate |

This is a **structural refinement of [[pac26]] Pillar 3**, not a replacement: it doesn't re-rank strength/freshness, it adds a second orthogonal axis (frame-setter vs. trigger) crossed with the zone PAC26 already assigns.
