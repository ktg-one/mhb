AI anthropology reveals a core cognitive mismatch: LLMs optimize for coherence; humans optimize for correctness.
- **Action:** Build a simple checklist:
  - [ ] Source cited?
  - [ ] Date verified?
  - [ ] Methodology reproducible?
  - [ ] Confidence interval stated?
- **Rule:** No output leaves your desk without passing this gate.

Boards do not punish tool use—they punish undisclosed risk.

Before any presentation, ask: "If this number is wrong, how would I know?"

- **Rule:** If you cannot break it, you are closer to trusting it.
